📚 ¿Qué es una ecuación?

📏 Primer Grado (Lineal)

La incógnita aparece con exponente 1. Siempre tiene exactamente una solución (si a ≠ 0).

Ejemplo: 3x + 2 = 11 → x = 3

ax + b = cx + d
x = (d - b) / (a - c)

📈 Segundo Grado (Cuadrática)

La incógnita aparece elevada al cuadrado. Puede tener 0, 1 o 2 soluciones reales.

Ejemplo: x² − 5x + 6 = 0 → x₁ = 3, x₂ = 2

Δ = b² - 4ac
x = (-b ± √Δ) / 2a

🔀 Discriminante (Δ)

  • Δ > 0: dos soluciones reales distintas
  • Δ = 0: una solución doble
  • Δ < 0: no hay soluciones reales

🔀 Sistemas 2×2

Dos ecuaciones con dos incógnitas. Métodos: sustitución, igualación, reducción.

a₁x + b₁y = c₁
a₂x + b₂y = c₂

🔁 Sistemas 3×3

Tres ecuaciones con tres incógnitas. Método: eliminación gaussiana.

a₁x + b₁y + c₁z = d₁
a₂x + b₂y + c₂z = d₂
a₃x + b₃y + c₃z = d₃

⚡ Métodos de resolución

  • Sustitución: despejar una variable y sustituir
  • Igualación: despejar la misma variable en ambas
  • Reducción: multiplicar y sumar para eliminar
  • Gaussiana: matriz de coeficientes

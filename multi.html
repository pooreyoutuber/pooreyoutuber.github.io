How to Use the Online Video Trimmer

  1. Upload your video – Click the upload area or drag and drop any common video file (MP4, WebM, MOV, MKV, AVI, etc.). The tool accepts files of substantial size; practical performance depends on your device’s available memory (many users successfully process multi-gigabyte files).
  2. Preview the full video – Once loaded, the video appears in the player so you can watch and decide exactly which part you need.
  3. Set the start and end points – Use the time input boxes (you can type seconds or HH:MM:SS format) or drag the two range sliders. The selected duration updates live so you always know how long the final clip will be.
  4. Preview your selection – Click “Preview Selection” to play only the chosen portion and confirm it looks perfect.
  5. Trim & Process – Hit the big Trim button. The browser records the selected segment using modern MediaRecorder technology. A progress bar keeps you informed.
  6. Download – When processing finishes, a green download button appears. Save the trimmed video to your device instantly.

Technical Notes & Performance Tips

The tool uses the HTML5 video element combined with the MediaRecorder API and MediaStream capture. When you click Trim, the video is seeked to the start time, played at normal speed while the stream is recorded until the end time is reached. The resulting Blob is then offered for download.

For the best experience:

  • Use a recent version of Google Chrome, Microsoft Edge, or Mozilla Firefox.
  • Close other heavy tabs if you are processing very large files.
  • Prefer MP4 or WebM source files for maximum compatibility.
  • If a file fails to load, try converting it first with another free tool or check that the codec is supported by your browser.

Please note that true lossless stream-copy trimming (without re-encoding) is not possible with pure browser APIs in a cross-browser way without additional WebAssembly modules that require special server headers. This tool prioritizes maximum compatibility and privacy by using the reliable MediaRecorder approach that works on GitHub Pages and almost every modern hosting environment.

Frequently Asked Questions

Is my video uploaded to a server?
No. Never. All processing happens inside your browser using JavaScript and native browser APIs.

What is the maximum file size?
There is no hard limit coded into the tool. Practical limits depend on your device’s RAM and browser. Many users successfully trim multi-gigabyte videos. Extremely large files (10 GB+) may require a powerful computer with plenty of free memory.

Does it work on mobile phones?
Yes on modern Android and iOS browsers, although performance and file-size handling are better on desktop computers.

Will the quality stay the same?
The output is re-encoded by the browser’s MediaRecorder. Quality is generally excellent for most sharing and editing purposes. For absolute bit-perfect cuts, a desktop tool with stream copy is still recommended for professional archival work.

Can I trim audio-only files?
This version focuses on video. For pure audio trimming, other specialized tools are better suited.

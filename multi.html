Traceroute Checker

Run on your computer

Traceroute shows each network hop between your device and a server, with the time each one takes. A browser cannot send these probes, so enter a target to get the right command, and use the guide below to read the output.

How to read the output

Each line is one hop, numbered from 1. The three numbers are round-trip times in milliseconds for three probes. A * * * line usually means that router does not reply to probes, which is normal and not a fault unless every hop after it also times out. A sudden jump in time often marks a long-distance link, while a timeout that continues to the end suggests the target blocks these probes or is unreachable.

IPv4 to IPv6 Converter

Runs in your browser

Ping Helper

Run on your computer

Ping measures round-trip time to a host. A browser cannot send ICMP packets, so enter a target and copy the ready-made commands for Windows, macOS or Linux.

High or increasing latency, or packet loss, can point to congestion or a problem on the path. Some hosts and firewalls block ping.

About Pooreyoutuber Networking Tools

Pooreyoutuber Networking Tools is a free set of utilities for developers, system administrators, students and website owners. Networking problems are often hard to see: a page does not load, a link is broken, a form is unusable for some visitors, or a domain points to the wrong server. These tools (accessibility, postcode validator & location finder, bulk URL, HREF extractor, port checker, HTTP/2, HTTP request, traceroute, IPv4/IPv6, domain to IP, domain extractor, IP search, subnet calculator, ping helper, MX lookup, SSL checker and user-agent parser) help you look at each part of the problem in a simple way. There is nothing to install and no account to create. Open the page, enter your input, and read the result.

How to use this page

Use the chips at the top to jump to any tool, or scroll through the list. Each tool has a short description, the input you need, and a results area. Some tools run entirely in your browser, so your data stays on your device. Others use a public service, and the description tells you which one. A few tools, such as the port checker and traceroute helper, need access to your network that a web page cannot have, so they provide the exact commands to run on your own computer.

Why browser limits exist

Web browsers are designed to protect you. A website is not allowed to open arbitrary network connections, send raw network packets, or read the responses of other sites unless those sites explicitly allow it. This is why some checks are limited on a web page. We explain each limit clearly, so you know what the result means and what to run on your computer to confirm it.

Accessibility Checker

Accessibility is about making a website usable for everyone, including people who use screen readers or keyboards. The checker reads your HTML and flags common problems: a missing language setting, a page without a title, images without alternative text, links and buttons with no name, form fields without labels, headings that skip levels, and iframes without titles. Fixing these issues often makes a site easier to use for everyone. Remember that automated checks cannot test colour contrast or real user experience, so also test with a keyboard and a screen reader.

Postcode Validator

Postal codes follow different formats in each country. Some are five digits, some mix letters and numbers, and some include a space or dash. The validator checks whether a code matches the expected pattern for the country you choose. It is useful for checkout forms, shipping tools and data imports. It cannot confirm that the address exists, so use a delivery address service for that.

Bulk URL Checker

When you maintain a large site or a list of resources, broken links appear over time. The bulk checker tests many URLs at once. It first checks the syntax, so a typo such as "htp" is caught immediately, and then sends a request to see whether a server responds. Because of browser security, the exact status code of a cross-site request cannot be read, so use the result as a fast reachability check and confirm important URLs with curl.

HREF Links Extractor

Links are the structure of the web. The HREF extractor collects every link from a block of HTML, resolves relative links against a base address, and labels each one as internal, external, anchor or other. This helps with SEO audits, link analysis, content inventories and research. Export the list to CSV to work with it in a spreadsheet.

Port Checker

A port is a numbered door on a server, and each service listens on a known port. Port 443 serves HTTPS, port 22 serves SSH and port 3306 serves MySQL. A port is "open" when a service accepts connections on it. Browsers cannot test arbitrary ports, so the tool runs a probe for web-style ports and gives you ready-made commands for Windows, macOS and Linux. The common ports table helps you identify what a number usually means.

HTTP/2 and HTTP/3 Checker

HTTP/2 and HTTP/3 are newer versions of the web's transfer protocol. They are faster because they handle many requests over one connection, and HTTP/3 uses a modern transport that reduces delays on unstable networks. To check a site, run the command shown on this page. The tool also reports which protocol was used to load the page you are on, which is a quick way to see the difference.

HTTP Request Checker

Developers often debug APIs by reading raw requests. A small mistake, such as a space before a colon in a header or a Content-Length that does not match the body, can cause a request to fail in confusing ways. The request checker reads the request line, checks each header, confirms that HTTP/1.1 requests include a Host header, and compares the body size with the declared length.

Traceroute Helper

When a connection is slow or fails, traceroute shows the path your data takes. Each hop is a router, and the timings help you locate where delay starts. Enter a target to get the correct command for your system. Remember that many routers do not answer probes, so a few asterisks in the middle of a route are usually harmless.

IPv4 and IPv6 Converter

The internet is moving from IPv4 addresses, which have about four billion possibilities, to IPv6 addresses, which are much larger. During this transition, networks use special forms to represent IPv4 addresses inside IPv6. The converter shows the IPv4-mapped form, the NAT64 form used for translation, and the 6to4 prefix. It also reverses an IPv4-mapped IPv6 address back to IPv4.

Domain to IP Converter

Every domain name points to one or more IP addresses through DNS. This tool asks a public DNS service for the A record (IPv4) and AAAA record (IPv6) of a domain and shows the answers with their time-to-live values. Use it to confirm where a domain points after a server move, or to check whether IPv6 is configured.

Domain Extractor

Text such as emails, reports and chat logs often contains website addresses. The extractor finds domains and full URLs, reduces each one to its domain name, and removes duplicates. It is useful for building lists for research, cleaning up data, or checking which sites a document mentions.

IP Address Search

An IP address can reveal approximate location, the organisation that owns the network, and the time zone. The search tool checks locally whether an address is public, private, loopback, link-local or multicast, then looks up the public details through a third-party service. Use it to investigate suspicious traffic or to understand where a visitor is connecting from. Location is approximate, usually at city level.

Postcode Location Finder

Enter a postal or ZIP code and a country to see the city, state or district, and map coordinates. The tool uses the free Zippopotam service. Coverage is good for many countries but not complete; always confirm important addresses with an official source.

Subnet Calculator

Plan IP ranges by entering an address and CIDR prefix (or netmask). The calculator shows network address, broadcast, usable host range, total hosts and wildcard mask.

Ping Helper, MX Lookup, SSL Checker & User-Agent Parser

Ping and SSL tools give you the exact commands to run on your computer because browsers cannot send ICMP or freely inspect certificates. MX lookup uses public DNS to list mail servers for a domain. The User-Agent parser gives a quick read of browser, OS and device from a log string.

Tips for the best results

Start with the simplest check. If a page does not load, test the domain with the DNS tool, then the port with the command, and then the HTTP request. Keep sensitive information such as passwords and tokens out of request checks, and remove them before you share a result. When you run commands on your computer, read the output carefully, because a timeout can mean a firewall rather than a broken service.

Privacy and browser support

Tools marked as running in your browser do not send your input anywhere. The DNS and IP lookups send only the domain or address you enter to the public service described on that tool. The tools work in current versions of Chrome, Edge, Firefox and Safari, on desktop and mobile.

Frequently asked questions

Can this page scan every port on a server? No. Browsers do not allow arbitrary port scans. Use the commands provided on the port checker tool, and only test systems that you own or have permission to test.

Why does a bulk check show "reachable" but not the status code? Browsers hide the response details of cross-site requests for security. Reachability tells you a server answered. Use curl for the exact status.

Is the postcode validator accurate for every address? It checks format only. A valid format does not guarantee that the address exists.

📚 Propiedades de las potencias y raíces

Reglas Fundamentales

  • aᵐ × aⁿ = aᵐ⁺ⁿ
  • aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • (aᵐ)ⁿ = aᵐˣⁿ
  • a⁰ = 1
  • a⁻ⁿ = 1/aⁿ

Raíces como Potencias

  • √a = a^(1/2)
  • ∛a = a^(1/3)
  • ⁿ√a = a^(1/n)
  • ⁿ√(aᵐ) = a^(m/n)
  • √a × √b = √(a×b)

Logaritmos

  • logₙ(a) = x ⟺ nˣ = a
  • log₁₀(a) = log(a)
  • logₑ(a) = ln(a)
  • log(a×b) = log(a) + log(b)
  • log(aⁿ) = n×log(a)

Casos Especiales

  • a¹ = a
  • a⁰ = 1
  • 0ⁿ = 0
  • 1ⁿ = 1
  • √1 = 1

Ejemplos Comunes

  • 2³ = 8 (dos al cubo)
  • 2⁴ = 16 (dos a la cuarta)
  • √9 = 3 (raíz cuadrada de 9)
  • ∛8 = 2 (raíz cúbica de 8)
  • log₁₀(100) = 2 (logaritmo en base 10)
